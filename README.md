---

## Overview

This repository holds the **brand system** and **UI/social mockups** for Bright Mindful Pages:

- Approved logo direction (**Gentle Companion** — page + seed emblem)
- Color palette, typography, and voice guidelines
- React mockups for product and social layouts
- Branding package + preview assets

It is primarily a design / identity workspace, not a full production app.

---

## Brand snapshot

| Item | Detail |
|------|--------|
| Mission | Simple tools to notice how you are doing, build habits, and reflect without pressure |
| Audience | Adults seeking organized, approachable self-care tracking |
| Logo | Gentle Companion (page + seed + soft glow) |
| Voice | Gentle, clear, practical — never clinical, childish, or pressuring |

**Palette:** Deep Tide `#203B36` · Leaf Note `#668C78` · Morning Glow `#E09B5E` · Page Cream `#F8F5EF`

Full guide: [`branding-package/BRIGHT-MINDFUL-PAGES-BRAND-GUIDE.md`](branding-package/BRIGHT-MINDFUL-PAGES-BRAND-GUIDE.md)

## Install & run mockups

```bash
git clone https://github.com/0utLawzz/Mindful-Pages.git
cd Mindful-Pages

# Workspace uses pnpm
pnpm install

cd artifacts/mockup-sandbox
pnpm install
pnpm run dev
```

Open the URL printed by Vite to browse the mockup sandbox.
