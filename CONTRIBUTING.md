# Contributing to Mindful Pages

## Setup

```bash
git clone https://github.com/0utLawzz/Mindful-Pages.git
cd Mindful-Pages
pnpm install
cd artifacts/mockup-sandbox && pnpm install && pnpm run dev
```

## Guidelines

- Keep brand voice gentle and non-clinical (see brand guide).
- Prefer focused PRs for mockups or brand assets.
- Do not introduce medical or therapeutic claims in copy.
